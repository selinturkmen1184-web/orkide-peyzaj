# Orkide Peyzaj

Orkide Peyzaj için hazırlanan modern, mobil uyumlu kurumsal web sitesi.

## Canlı site

[selinturkmen1184-web.github.io/orkide-peyzaj](https://selinturkmen1184-web.github.io/orkide-peyzaj/)

## Geliştirme

Node.js `>=22.13.0` gerektirir.

```bash
npm install
npm run dev
```

Kontrol komutları:

```bash
npm run lint
npm test
```

`docs/` klasörü GitHub Pages için hazırlanmış statik yayını içerir.
